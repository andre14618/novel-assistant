- [warning] The Gray Salt Mine deep-salvage run requires iron-thread binding and has killed three men in the last six months; it is the only posting that pays before the tenth. (fact-4) — The same Gray Salt posting is first established as a deep-salvage mine run with iron-thread binding and a three-death history, then in beat 4 described as a road haul contract that is safe and paper-trail-visible.
